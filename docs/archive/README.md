# Archívum

Ez a mappa lezárt, történeti anyag: a teljesen megvalósított backlog-tételek
tömör összefoglalója (`08-backlog-closed.md`, folyamatosan bővülő napló,
az első kör doktor-nap narratívájával és architekt-triázzsal együtt) és a
hozzájuk tartozó döntési összefoglalók (`backlog/`).

Egy tétel akkor kerül ide, amikor a `CLAUDE.md` „Backlog-tétel lezárása"
checklistje szerint lezárul: a tartósan érvényes döntései előtte bekerülnek
a `docs/01`–`07` fő dokumentumokba (döntés-tábla `D22`-től, illetve a
megfelelő funkcionális/nyomtatvány/technológia szakaszokba). **Erre a
mappára sehonnan nem szabad hivatkozni** — sem a `docs/*.md`
fájlokból, sem a forráskódból, sem a `CLAUDE.md`-ből. Ha egy döntés
háttere kell, a fő dokumentumok az aktuális forrás; ez a mappa csak azért
maradt meg, hogy a döntéshez vezető eredeti gondolatmenet a git history-n
kívül is kereshető legyen.
